# AI Resume Analyzer 2.0

AI Resume Analyzer 2.0 is an intelligent web application that analyzes resumes using **Artificial Intelligence, Machine Learning, and Natural Language Processing (NLP)**.

The system extracts skills from a resume, predicts the most suitable **career role**, identifies **missing skills**, and provides **career guidance through an AI chatbot**.

This project demonstrates the practical integration of **Data Science, Machine Learning, and Web Development** to build a real-world AI product.

---

# Project Objective

The main objective of this project is to help students and job seekers understand:

* Which **career role** best matches their skills
* What **skills are missing**
* How they can **improve their resume**
* What technologies are required for their desired career

The system acts as an **AI-powered career advisor**.

---

# 🧠 Key Features

###  Resume Input

Users can:

* Paste resume text
* Upload a **PDF resume**

The system automatically extracts and analyzes the content.

---

### AI Job Role Prediction

Using **Machine Learning**, the system predicts the most suitable job role such as:

* Data Scientist
* AI Engineer
* Backend Developer
* Frontend Developer
* Data Analyst
* UI/UX Designer
* Software Engineer

---

### Skill Extraction

The system scans the resume and identifies technical skills such as:

* Python
* Machine Learning
* SQL
* JavaScript
* TensorFlow
* Power BI
* React
* Pandas
* NumPy

---

### Skill Dashboard

A modern dashboard displays:

* Predicted career role
* Confidence score
* Detected skills
* Missing skills

It also visualizes skills using **interactive charts**.

---

### Skill Gap Analysis

The system compares detected skills with **industry-required skills** and highlights missing ones.

Example:

Detected Skills:
Python, Pandas, SQL

Missing Skills:
Statistics, Machine Learning

This helps users improve their career readiness.

---

### AI Career Chatbot

An integrated chatbot answers career-related questions such as:

* "What skills are needed for Data Science?"
* "How to become an AI Engineer?"
* "What does a Backend Developer need to learn?"

The chatbot provides instant career guidance.
